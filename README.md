# Vita-Drip Lounge Website

Static online booking website for Vita-Drip Lounge.

## Files

- `index.html` - page structure and booking sections
- `styles.css` - responsive spa-inspired styling
- `script.js` - service data, filters, date/time slots, and booking flow

## Run

Open `index.html` in a browser. No build step is required.

The booking form currently creates a client-side request and prepares a
WhatsApp admin message to `+263771828667`, with an email fallback to
`bookings@vitadriplounge.com`. Connect it to a booking API, form endpoint, or
live email address before production use.
